# 정상 운행 중입니다!

고장 난 우주 택배선의 마지막 야간 근무. 산소를 만들면 엔진이 뜨거워지고, 냉각하면 전력이 떨어지고, 발전하면 산소가 사라집니다. 120초 동안 선박을 유지해 케플러 우편 기지에 배송하세요.

**플레이:** https://ys143112.github.io/button_MVP/

## 발견하는 조종실

버튼에는 효과 수치와 부작용을 미리 표시하지 않습니다. 설명서·안내 문구·조작 로그에서도 자원 공식을 숨기고, 실제 계기 변화와 장치 연출로 관계를 발견합니다. 산소 펌프, 냉각 팬, 발전 코일, 용접 스탬프, 환기 셔터, 회로 스위치가 서로 다르게 반응합니다. 창밖에도 기포·성에·전기·불꽃·기류·회로 입자가 나타납니다. 효과 줄이기는 이러한 움직임을 끕니다. 아래 표는 개발 참고용입니다.

## 조작

마우스·터치로 장치를 누르거나 숫자 1–6을 사용합니다. Space / Escape는 일시정지입니다. 탭을 벗어나면 자동으로 정지합니다. 시작 화면의 매뉴얼에서 기본 규칙을 설명합니다.

| 장치 | 효과 | 대가 / 제한 |
| --- | --- | --- |
| 산소 주입 | 산소 +24 | 열 +10, 전력 −5 / 5초 |
| 급속 냉각 | 열 −26 | 전력 −16 / 6초 |
| 비상 발전 | 전력 +27 | 산소 −12, 열 +4 / 6초 |
| 선체 용접 | 선체 +24 | 전력 −10, 냉각 잠금 4초 / 9초 |
| 비상 환기 | 열 −16, 화재·필터 복구 | 산소 −15 / 7초, 24초 해제 |
| 회로 우회 | 전력 +10, 합선·드론 복구 | 열 +9 / 10초, 40초 해제 |

산소·선체가 0이 되거나 엔진이 100도에 도달한 뒤 3초 동안 복구하지 못하면 패배합니다. 전력 부족은 산소 감소를 가속합니다. 8종 사고(배관 누출, 화재, 합선, 충돌, 결빙, 드론 파업, 필터 막힘, 발전기 진동)는 5초 전에 원인과 해결 장치를 표시합니다. 예고 중에도 예방할 수 있습니다. 사고는 시간 만료로도 끝나므로 영구 교착을 막습니다.

반복 조작, 자원 임계치, 시드 기반 항로 사건이 함께 작동합니다. 시간이 흐르면 사건 간격과 기본 부하가 증가합니다. 높은 생존 자원과 적은 조작은 점수에 유리합니다. 최고 점수, 도착 횟수, 음향·효과 설정은 로컬 저장소에 보관합니다. 저장소나 오디오가 차단되어도 플레이할 수 있습니다.

## 실행 및 검증

Node.js 22 이상:

```sh
npm ci
npm run dev
npm test
npm run balance
npm run build
npx playwright install --with-deps chromium
npm run test:e2e
```

개발 URL은 `http://localhost:5173/button_MVP/`입니다. 로컬 Playwright는 `/usr/bin/chromium`을 사용합니다. 해당 경로가 없으면 설치 후 `CI=1 npm run test:e2e`로 Playwright 브라우저를 사용하세요.

- `src/engine.ts`: DOM·Phaser에 독립적인 시뮬레이션, 고정 시드 난수, 조작, 사고와 승패
- `src/scene.ts`: 직접 그린 Phaser 2D 우주 창, 화물선, 행성, 별과 상태 연출
- `src/main.ts`, `src/style.css`: 반응형 물리 패널, 화면 전환, 입력, 합성 음향과 저장
- `tests/engine.test.ts`: 자원·장치·8종 사고·예방·연쇄·공정성·종료 조건
- `tests/balance.ts`: 100개 시드 × 두 관리 전략. 자동 승률은 인간의 재미나 난도를 입증하지 않습니다.
- `tests/browser.spec.ts`: PC / 터치 화면의 실패·승리·정지·재시작·저장·콘솔 오류·화면 캡처

모든 게임 아트는 코드로 직접 그렸고 소리는 Web Audio로 합성했습니다. SIL Open Font License의 Noto Sans KR와 IBM Plex Mono를 Fontsource 패키지로 함께 제공합니다. 실행 중 외부 글꼴 요청이 없습니다. 유료 에셋과 서버는 없습니다. 효과 줄이기 설정은 깜빡임·버튼 애니메이션·별 이동을 줄입니다.

## 배포

`.github/workflows/deploy.yml`은 main 푸시와 PR에서 빌드, 단위·밸런스·브라우저 검사를 수행합니다. main 검사 통과 후 GitHub Pages에 배포합니다. 브라우저 캡처는 Actions의 `browser-evidence` 아티팩트에 저장됩니다. GitHub Settings → Pages → Source는 **GitHub Actions**로 지정해야 합니다. Vite base는 `/button_MVP/`로 고정되어 있습니다.

## 알려진 한계

실제 iOS / Android 기기, Safari와 Firefox의 검증은 포함하지 않습니다. 터치 검사는 Chromium 모바일 에뮬레이션입니다. Phaser 의존성 때문에 초기 JS가 약 1.2MB(압축 전)입니다. 게임 진행에는 외부 API가 필요하지 않습니다.
